# AlignWell Website README (MVP)

## Project Overview
AlignWell is a one-therapist online platform providing text and video therapy for young adults (18–34). The site is mobile-first, SEO-optimized, and designed for quick, stigma-free engagement.

---

## Core Features
- Hero & Pain Points sections to engage users immediately
- Services section with 3 therapy offerings
- About section introducing the licensed therapist
- Testimonials section with anonymized client quotes
- How It Works, Pricing, FAQ, and Contact sections
- Footer with copyright, and privacy

---

## Tech Stack
- HTML, CSS, JavaScript
- Responsive design, mobile-first
- SEO-friendly semantic HTML
